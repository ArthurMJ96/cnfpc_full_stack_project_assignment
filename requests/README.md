## Usage

To use this bruno collection, you need to open it using the [useBruno App](https://www.usebruno.com/downloads) or use the [Bruno VSCode Extension](https://marketplace.visualstudio.com/items?itemName=bruno-api-client.bruno).

### Environment Variables
Every request uses the `{{base_url}}` variable.   
Make sure to select the LOCAL environment that I have provided, or create your own with the appropriate base_url (e.g., `http://localhost:8080`).
